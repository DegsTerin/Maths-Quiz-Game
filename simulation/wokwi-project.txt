Wokwi simulation reference

The repository contains the Arduino sketches, diagram.json, libraries.txt and
the reference layout in simulation/wokwi.png. A public Wokwi project ID has
not been published for this build.

Create a new Arduino Uno project at https://wokwi.com/projects/new/arduino-uno
and follow the "Simulate in Wokwi" section in the repository README.
